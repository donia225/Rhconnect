📘 Structure du Frontend RHConnect

Le frontend du projet RHConnect est développé avec Angular et repose sur le thème Datta Able pour l’interface d’administration.
L’application est organisée selon les différents rôles utilisateurs et leurs interfaces correspondantes.

🎨 Structure principale

L’ensemble des interfaces se trouve dans le dossier :

src/app/theme/layout/

on distingue trois principales sections :

acceuil/ → partie client destinée aux candidats.

admin/ → espace administration pour les gestionnaires RH et recruteurs.

employe/ → espace réservé aux employés pour le suivi de carrière.

Chaque section possède sa propre structure, son layout et ses composants dédiés selon le rôle de l’utilisateur.
